# 🎬 How to Use the Premium Media Keyboard

## Quick Start Guide

### 🚀 Accessing the Media Keyboard

**Option 1**: Click the **🎬 GIF button** next to the message input  
**Option 2**: Click the **😊 Emoji button** for quick emoji access (old picker)  

---

## 😊 Using the Emoji Picker

### Step 1: Open Emoji Tab
1. Click the **🎬 button** in the message input area
2. You'll see the media keyboard popup
3. The **😊 Emoji** tab is selected by default

### Step 2: Browse Categories
Click any category icon to view emojis:
```
🕒 Recent     - Your recently used emojis
😀 Smileys    - Facial expressions
👍 Gestures   - Hand gestures
❤️ Hearts     - Love & hearts
🐶 Animals    - Animals & nature
🍕 Food       - Food & drinks
⚽ Activities - Sports & hobbies
✈️ Travel     - Transport & places
⚡ Objects    - Symbols & objects
🏁 Flags      - Country flags
```

### Step 3: Insert Emoji
- Click any emoji to **insert it into your message**
- Continue typing your message
- Press **Send 🚀** to send

### 💡 Pro Tips:
- Recent emojis are saved automatically
- Search for emojis using the search bar
- Keyboard stays open for multiple selections

---

## 🎬 Using the GIF Picker

### Step 1: Open GIF Tab
1. Click the **🎬 button** in the message input area
2. Click the **🎬 GIF** tab at the top
3. Wait for trending GIFs to load

### Step 2: Browse or Search
**Browse Trending:**
- Scroll through 30 trending GIFs
- Hover over any GIF to preview

**Search GIFs:**
1. Click the search bar
2. Type keywords (e.g., "happy", "dance", "cat")
3. Press Enter or wait 300ms
4. Results appear instantly

### Step 3: Send GIF
1. Click any GIF
2. It sends **immediately** to the chat
3. No need to press Send button

### 🎯 Search Examples:
```
"happy"      - Happy emotions
"dance"      - Dancing animations
"cat"        - Funny cat GIFs
"party"      - Party celebrations
"thumbs up"  - Approval GIFs
"love"       - Romantic GIFs
"laugh"      - Laughing animations
"celebration" - Success celebrations
```

## 🐛 Troubleshooting

### GIFs Not Loading?
**Solution**:
1. Check your internet connection
2. Wait a few seconds and try again
3. Refresh the page (F5)
4. Clear browser cache

### Search Not Working?
**Solution**:
1. Type at least 2 characters
2. Wait 300ms for debounce
3. Check keyboard/input focus
4. Try different search terms

### Media Keyboard Won't Close?
**Solution**:
1. Click the × button (top right)
2. Click outside the keyboard
3. Press Esc (when shortcut enabled)
4. Click message input area

### Emojis Not Inserting?
**Solution**:
1. Make sure message input is focused
2. Try clicking the emoji again
3. Refresh the page
4. Clear browser cache

### GIF Sends Instead of Preview?
**Note**: This is **intentional**! GIFs send immediately when clicked for faster messaging.
